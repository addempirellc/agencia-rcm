# 🏦 Panel de Agencia — Surplus Funds Recovery

**Sistema de gestión de leads para agentes que recuperan fondos excedentes de subastas de impuestos (Tax Deed Surplus) en condados de Florida.**

Esta herramienta te permite organizar prospectos, dar seguimiento a cada caso, registrar llamadas y mantener un pipeline visual de tu proceso de recuperación. Está diseñada para ser ligera, rápida y funcionar completamente en el navegador sin necesidad de servidor.

---

## ✨ Características principales

- 📊 **Dashboard ejecutivo** con estadísticas en tiempo real: total de leads, balance en pipeline, casos firmados/pagados y pendientes de contacto.
- 📋 **CRUD completo de leads**: agregar, editar, eliminar y filtrar por nombre, dirección, condado, número de tax deed o estado.
- 🔄 **Pipeline visual por etapas**: Sin contactar → Intentado → Interesado → Contrato enviado → Firmado → Pagado (incluye opciones de rechazo).
- 📤 **Importación masiva desde CSV** (texto separado por comas) para cargar listas de condados rápidamente.
- 💾 **Respaldo manual en JSON** con botones de Exportar/Importar, para que nunca pierdas tus datos aunque falle el almacenamiento local.
- 📞 **Guion de llamadas integrado** con frases clave para cada momento de la conversación.
- 🗺️ **Referencia rápida de condados** con enlaces a portales oficiales y clasificación de dificultad (Fácil/Difícil).
- 🌙 **Interfaz oscura**, responsive y optimizada para trabajo diario.
- ⚡ **Persistencia local** (localStorage) con mensajes de estado en tiempo real.

---

## 🎯 ¿Para quién es?

- Agentes de recuperación de fondos excedentes (surplus funds).
- Firmas de asesoría legal o financiera que manejan casos de tax deeds.
- Inversores inmobiliarios que rastrean oportunidades en subastas.
- Profesionales que necesitan organizar prospectos y dar seguimiento a procesos de reclamación.

## 🛠️ Tecnologías utilizadas

- **HTML5 + CSS3** (interfaz nativa, sin dependencias externas).
- **JavaScript vanilla** (sin frameworks, código ligero y autónomo).
- **localStorage** para persistencia de datos en el navegador.
- **JSON** para importación/exportación de respaldos.

---

## 🚀 Cómo usarlo

1.  Clona este repositorio o descarga el archivo `index.html`.
2.  Ábrelo con cualquier navegador moderno (Chrome, Edge, Firefox, etc.).
3.  Comienza a agregar leads o importa una lista desde la pestaña **Leads**.
4.  Utiliza los botones de **Exportar datos** e **Importar datos** (en la barra superior) para hacer copias de seguridad o transferir tu información entre dispositivos.

> ⚠️ **Importante:** Los datos se guardan en el almacenamiento local de tu navegador. Si limpias el historial o usas un navegador diferente, perderás la información. **Usa la exportación periódica para tener respaldos seguros.**
